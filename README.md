# Поросячьи бега — браузерная игра

Браузерная гонка на свиньях. Откройте игру по ссылке GitHub Pages в Safari на iPhone (или в любом другом браузере). Её также можно добавить на экран «Домой» как полноэкранное приложение.

## Как играть

1. Выберите одну из пяти свинок и сложность.
2. Нажмите «ТОПАЙ!», чтобы начать забег.
3. Чем чаще нажимаете по экрану, тем быстрее бежите.
4. Кнопка «ПРЫЖОК» перепрыгивает барьеры.
5. Свайпами влево и вправо можно менять дорожку.

На трассе лужи грязи замедляют, яблоко даёт ускорение, а золотой жёлудь включает турбо. Против вас бегут четыре свинки с ИИ. На финише — пьедестал и рекорд времени.

Игра работает офлайн после первой загрузки.
